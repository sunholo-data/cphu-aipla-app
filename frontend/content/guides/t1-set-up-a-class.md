::: callout-note
## Where this fits

A **class** is the starting point for everything else. It holds your students
(as anonymous groups, no personal accounts) and the activities you build for
them. Do this once per class; it takes about three minutes. Afterwards, follow
*T2 — Create your first activity*.

The **Getting started** card at the top of *Classes* ticks these steps off as
you go and links each one to the right control — this guide is the same walk,
written out.
:::

## What a class is

In AIPLA a **class** is a container you own. It has:

- one or more **group codes** — the short codes students type to join. Students
  do not create accounts and do not log in; the group code is all they need.
- the **activities** you assign to it (guide *T2*).
- a **tutor** — who teaches this class: its name, picture, voice, tone and
  teaching approach, in one choice. Leave the default or change it later.

Everything below is done in your browser. You do not need a developer.

::: callout-tip
## The co-pilot can do this for you

On *Classes*, click **Ask AIPLA** in the header and choose **Class co-pilot**.
You can create a class and mint group codes by asking it in plain language,
instead of using the forms below — see *T4 — Author with the AI co-pilot*.
:::

## Step 1 — Create the class

From your teacher area, open **Classes** and select **New class**. Give the
class a **name** — for example, *"Physics 2.g, autumn 2026"* — and, optionally,
a short description. Select **Create**.

![The New class form: a name and an optional description.](/guides/assets/t1-01-new-class.png)

Your new class now appears in the class list, alongside any others you own.

![The class list shows each class with its group codes, activities and tutor.](/guides/assets/t1-02-class-list.png)

## Step 2 — Mint a group code

Open the class with **Manage**. A new class has no group codes yet, so select
**New group**. AIPLA generates a short code and copies it to your clipboard.

![Selecting New group mints a code students use to join.](/guides/assets/t1-03-mint-group.png)

You can mint more than one group code for the same class — for example, one per
table group or per lab pair — so you can tell their work apart in reports.

## Step 3 — Share the code with students

Beside each code, select **Copy join link** and give students that link. It
carries the address and the code together, so nobody lands on the wrong AIPLA
site — a code works only on the site it was made on. (**Copy code** copies just
the code, for students who are already on the right page.) They open the link
and they are in — no login, no personal account (see *S1 — Join and use your
tutor*). Anything they do is grouped under that code, so your class reports
stay organised.

If you want to remember who is behind each code, open **Class list** on the
class page: write the names next to each code and **Download as Excel**. The
names stay in your browser on this device — AIPLA never receives them.

If a code leaks, select **Revoke** beside it. The code stops working at once
and can never be reissued; the group's work is kept. Mint a new code for the
group with **New group**.

::: callout-tip
Group codes are how you separate one class — or one lab group — from another in
the reports. Mint a fresh code for each group you want to track separately.
:::

## Step 4 — Choose the tutor (optional)

Under **Class settings** on the class page, **Tutor** sets who teaches every
activity in this class — name, picture, voice, tone and teaching approach, in
one choice. Leave it on the default, or pick another.

### Make your own tutor

Any teacher can write a teaching approach and build a tutor on it; you do not
need a researcher account. Open the **Teaching approaches** link beside
*Tutor* (or **Approaches** in the account menu, top right):

1. On the **Your approaches** tab, select **New approach**. Give it a **Name**, a
   **One-line summary**, and write **What the tutor is told** in full, as if
   briefing a teaching assistant. Select **Save**.
2. On the **Tutors** tab, select **New tutor**. Give it a **Name**, pick your
   approach under **Teaching approach** (your own approaches are listed after
   the seven published ones), choose a **Face and voice**, and select **Create
   tutor**. To change only the approach of an existing tutor, select the branch
   icon beside it (*Make a variant of …*) instead.
3. Back on the class page, pick your new tutor under **Tutor**.

The seven published approaches can be read on the **Approaches** tab but not
changed — they are maintained by the research team.
