This guide describes the opening controls. Classroom introduction advice is
awaiting pedagogical review.

## Set what students see first

Open your activity for editing. Under **Lesson**, find **What students see
first**, below the teaching goal. The teaching goal is an instruction for the
tutor; **Student introduction** is text your students read above the chat.

Write the introduction in the activity's chosen language. You can use Markdown
for emphasis and lists. The preview below the fields updates as you type.
Leave the introduction empty to use the activity name, first workspace item
and any checklist steps as the default. The privacy notice stays visible even
when students collapse the introduction panel.

## Choose who introduces the activity

The tutor introduces itself by name as an AI that helps students think. By
default, it also names the activity and its first step, then asks a question.
If you wrote the student introduction, the tutor is told it is already on
screen and should avoid repeating it.

Select **I'll introduce this activity in class myself** to skip the tutor's
activity walkthrough. The tutor still introduces itself and asks one question
about the activity. The introduction panel remains available to students.

## Set starter questions

Use **Add starter prompt** to write up to four short questions in the
activity's language. Students can tap one to send it as their own chat message.
These are suggestions for students, not instructions to the tutor. Remove all
of them to restore the default suggestions.

The activity co-pilot can propose an introduction and starter questions from
your activity's goal and workspace. You can edit each proposal before applying
it. Apply updates the draft; **Save** or **Create activity** stores your changes.

## Preview before sharing

Save the activity, then use **Try as student** to open the real student view.
Read **How to get started** and the tutor's first message. Check the language,
first step and starter questions. The getting-started checklist on **Classes**
has a reminder to check this opening before sharing the join link.

Students can reopen their introduction panel at any time and use its link to
[the student guide](s1-join-and-use-your-tutor) without closing their activity.
