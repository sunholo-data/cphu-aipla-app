- During simulations, **have events prompt a response from Mikkel when a question
  set is over.** Currently it just records the answers, and you have to prompt it
  yourself.
- Maybe mess around with the simulations a bit.
- **The tutor could manipulate the simulations for the student under certain
  conditions.**
- The tutor chooses the simulation settings (or reveals a document/image) when
  it judges the student needs to see it.

### Conditional content: concept maps as tech trees

- The system should have a number of drawings and images to show, **but not the
  answer**.
- Could we reveal images/documents **conditionally on app state**?
- Concept maps are like tech trees for unlocking content.
- **"I don't want students to tick off concept maps, but the AI tutor to tick it off."**

- Make the UI for finding concepts easier.
