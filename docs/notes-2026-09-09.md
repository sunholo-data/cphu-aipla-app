## Chat history across activities

- **We will add a feature to let chat history across activities be shared**

> **Aside, not triage.** `db/group_sessions.py` keys the active session per
> `{group_id}:{activity_id}` — ALS-1 made that change deliberately, *"a group now
> runs MANY activities, each with its own conversation"* — and the write is
> **first-wins** specifically so a stray session cannot orphan a conversation

> and tested, which makes this a **revision of a decision**, not a gap to fill.

> `busy-garden-11` report above. Both belong in one design pass.
