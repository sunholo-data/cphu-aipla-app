Bølger: v = f·λ og interferensWaves: v = f·λ and interference

Skru på frekvens og bølgelængde, se bølgen bevæge sig, og undersøg selv sammenhængen v = f·λ. Skift til interferens for at se to bølger lægge sig sammen. Adjust frequency and wavelength, watch the wave move, and work out the relationship v = f·λ for yourself. Switch to interference to see two waves add together.

PeriodePeriod T = 0.50 s
Målt på skærmen:Read from screen: f = 2.0 Hz, λ = 2.0 m
Prøv: sæt λ₁ = λ₂ og skru på fasen — 0° og 180°.Try: set λ₁ = λ₂ and change the phase — 0° vs 180°.

Din opgave — regn selvYour task — you do the maths

  1. Læs frekvensen f og bølgelængden λ af på skærmen. Beregn bølgens hastighed med v = f·λ.
  2. Read the frequency f and wavelength λ from the screen. Work out the wave speed using v = f·λ.
  3. Fordobl frekvensen. Hvad sker der med hastigheden? Og hvis du i stedet fordobler bølgelængden?
  4. Double the frequency. What happens to the speed? And if you double the wavelength instead?
  5. Hvilken sammenhæng er der mellem periode T og frekvens f? Tjek med tallene på skærmen.
  6. What is the relationship between period T and frequency f? Check it against the numbers on screen.

Din opgave — undersøgYour task — investigate

  1. Sæt λ₁ = λ₂ og fase = 0°. Hvad sker der med summen? (konstruktiv interferens)
  2. Set λ₁ = λ₂ and phase = 0°. What happens to the sum? (constructive interference)
  3. Behold λ₁ = λ₂, men sæt fasen til 180°. Hvad sker der nu, og hvorfor? (destruktiv interferens)
  4. Keep λ₁ = λ₂, but set the phase to 180°. What happens now, and why? (destructive interference)
  5. Gør bølgelængderne lidt forskellige. Beskriv mønstret i summen (svævninger).
  6. Make the wavelengths slightly different. Describe the pattern in the sum (beats).

Simuleringen viser bølgerne og lader dig aflæse f og λ — men den regner ikke hastigheden ud for dig. Det er din opgave. The simulation shows the waves and lets you read off f and λ — but it doesn't calculate the speed for you. That's your job.
