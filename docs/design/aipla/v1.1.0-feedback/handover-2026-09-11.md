## Traps found this session — each cost real time

- **A CI gate that failed on the calendar.** `check-tutor-docs` compared
  generated docs byte-for-byte while the generator stamped `reviewed:` with
  *today*, so it went green on the day docs were generated and red the next
  morning, for all 15 at once, on whatever commit came next. I misread it as my
  own commit breaking the build. Fixed at the cause.
- **`verify-chat-logs` failing for a reason that was not the pipeline.** The
  demo group's turn was refused by the spend gate before an agent ran. It looked
  exactly like a broken chat-log pipeline.
- **BigQuery views that had never existed anywhere.** `create_views` defaulted
  false and was never flipped. The first attempt to enable failed on
  `Field name latency_ms does not exist in STRUCT<…>` — the sink omits
  never-populated fields, so a struct-member view is creatable only after every
  column it names has been written at least once. Now read with `JSON_VALUE`,
  which is NULL-safe for absent paths.
- **My own guard caught my own change, in CI rather than locally**, because I
  ran the backend suite before the terraform rewrite and not after.
